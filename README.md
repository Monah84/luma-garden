# Wake the Garden — public site

The public pages for the Wake the Garden app. Plain HTML and one stylesheet, served
by GitHub Pages. No build step: edit a file, commit, push, and it is live in
about a minute.

| Page | Purpose |
| --- | --- |
| `index.html` | Landing page. **Use this as the store Support URL.** |
| `privacy.html` | **Use this as the store Privacy Policy URL.** Both stores require it. |
| `why.html` | The personal story and the fundraiser link. |
| `style.css` | Shared styling. |

## Before sharing this widely

- `why.html` still contains `FUNDRAISER_LINK_GOES_HERE`. Replace it with a real
  URL, or delete that block.
- If the privacy policy changes, update the date at the top of `privacy.html`.
  Both stores expect the hosted policy to match what the app actually does.

## The game source is not here

This repository is public because GitHub Pages requires it. The game source
lives in a separate, private repository.
